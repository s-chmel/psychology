# Ясность в отношениях — прототип лендинга

Статичный лендинг (один `index.html` + `assets/`). Без сборки и зависимостей; шрифты Literata и Onest подгружаются из Google Fonts.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите содержимое этой папки в корень.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)`.
3. Ссылка: `https://<username>.github.io/<repo>/`

## Что заменить
- `[Имя Фамилия]` в блоке «Кто будет работать с вами»
- Кнопка «Хочу ясность» сейчас открывает заглушку (`<dialog id="dlg">`) — подставьте ссылку на запись
